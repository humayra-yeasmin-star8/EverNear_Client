# EverNear Client (Next.js 16 + React 19)

## Commands

- `npm run dev` — dev server (Turbopack).
- `npm run build` — type-checks and lints as part of the build; use this for verification. No test setup exists.
- `npm run lint` — bare `eslint` over the project.

## Framework quirks

- **Read the bundled docs before writing code**: this Next.js version differs from training data. Guides live in `node_modules/next/dist/docs/` (see the block below).
- **React Compiler is enabled** (`reactCompiler: true` in `next.config.ts`). Do not add manual memoization (`useMemo`, `useCallback`, `memo`) for performance — the compiler handles it.
- **Tailwind v4, CSS-first**: no `tailwind.config.*`; theme tokens live in `src/app/globals.css`. CSS is loaded through the `@tailwindcss/turbopack` rule in `next.config.ts`.
- Routing is App Router only (`src/app`). `react-router-dom` is in dependencies but unused — do not use it.
- Typed routes/layout props are generated (e.g. `LayoutProps<"/">` types in `.next/**/types/`); trust them over imported generics.

## shadcn/ui — Base UI, not Radix

- `components.json` uses style `base-nova`, built on **Base UI** (`@base-ui/react`). Stock shadcn snippets from the docs use Radix — do not copy them in.
- `src/components/ui/*` is generated by the shadcn CLI; add components with `npx shadcn add <name>` rather than hand-writing them, and avoid editing generated files.
- Import aliases: `@/components`, `@/components/ui`, `@/hooks`, `@/lib` (→ `src/*`, see `tsconfig.json` / `components.json`).
- Icons come from `lucide-react`; class merging via `cn` stays in `src/lib/utils.ts`.
